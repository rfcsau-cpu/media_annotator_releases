## Media Annotator

Windows Portable Application – Beta Releases

Welcome to the official download repository for Media Annotator.

This repository provides precompiled Windows releases of Media Annotator. It contains downloadable application packages and release information.

### Download

Visit the [Releases](https://github.com/rfcsau-cpu/media_annotator_releases/releases) page to download the latest version.

[Latest Windows version: v1.3.0 Beta](https://github.com/rfcsau-cpu/media_annotator_releases/releases/tag/windows-1.3.0-beta)

### Windows Installation
Download the latest Media Annotator-Windows-x64.zip file from Releases.
Extract the ZIP archive to a folder of your choice.
Open the extracted folder.
Run Media Annotator.exe.

##### Important: 
- Keep all extracted files together. The application requires its supporting files and dependencies to run correctly.
